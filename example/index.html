This example takes .mca files, parses them, lists all the entities and their coordinates, and allows you to filter by the entity ID.
E.g. if you've died, dropped your items and can't remember where, you could search for a "diamond_pickaxe".

Select .mca file(s) from a save folder (e.g. C:\Users\Me\AppData\Roaming\.minecraft\saves\New World\entities).
More info on file locations can be found here.
